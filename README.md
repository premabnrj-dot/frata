# Frata

Fashion-first commerce for Indian D2C brands: storefront, checkout, COD,
shipping, WhatsApp, Instagram, Meta and Google in one place, with every order
judged on whether it was delivered.

```bash
npm install
cp .env.example .env.local   # fill in from Vercel / Supabase
npm run dev
npm test && npm run typecheck
```

Start with `CLAUDE.md` (rules), `docs/README.md` (map) and
`docs/research/2026-11-06-market-ux-and-stack.md` (why).
