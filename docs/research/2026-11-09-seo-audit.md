# Storefront SEO and sharing — what the code does today (audit, 2026-11-09)

Read-only audit of `src/app/s/[host]/` and its helpers at c6a8df9, for the SEO and sharing spec
(`docs/specs/2026-11-09-seo-and-sharing.md`). `[host]` = `src/app/s/[host]`.

## Covered
- **Product page** (`[host]/(shop)/products/[handle]/page.tsx`): editable seo title/description with defaults
  (`src/components/storefront/product-view.tsx`), canonical, OG title/description/image (first photo, 1200 wide, 4:5),
  ProductGroup/Product JSON-LD with variants, offers, availability (`src/domains/catalogue/seo.ts`), 308 for old
  handles (`product_handle_history`), noindex for unlisted/archived.
- **Home**: canonical, OG without image, `OnlineStore` JSON-LD (return policy, shipping service, Instagram sameAs).
- **robots.txt / sitemap.xml** per host; Disallow until published.
- **Console**: product "Search and sharing" panel — Google snippet preview, WhatsApp card preview, title/description
  with soft limits, handle with redirect note (`src/app/(console)/console/products/_components/seo-panel.tsx`).
- **Images**: WebP ladder 400–1600, srcset/sizes, width/height, LCP priority on the first photo/cards/hero
  (`src/components/storefront/photo.tsx`). Cached ISR pages (revalidate 60, tags), a 120 kB JS gate.

## Gaps
1. Canonical, sitemap, robots and JSON-LD always use `<slug>.frrata.shop`; own domains (D·2) not built.
2. Old shop names: 200 + client redirect (deliberate, keeps utm); collection renames 404 (no handle history).
3. OG images: products only, 4:5 portrait (not 1.91:1); none for home, collections, lists, policies. No twitter tags,
   no og:locale, og:type always website.
4. No meta description on lists, policies, paginated pages; collection descriptions untrimmed (to 2,000 chars).
5. No hreflang; `<html lang="en-IN">` always, Hindi only on a div; English titles for Hindi shops.
6. No shop favicon (`data:,`), apple-touch icon, manifest or theme-color. `logo_url` has no setter at all.
7. JSON-LD: no BreadcrumbList, WebSite, ItemList, AggregateRating; no gtin/mpn; free-shipping threshold and handling
   time passed in and dropped; default description drops "Ships from <city>" (city always null).
8. No GTIN/barcode/MPN/brand fields (Merchant Center needs them for many categories).
9. Sitemap: no images, lastmod = publish date only, no pagination, no index; empty collections listed.
10. No alt-text editor (the action accepts `alt`); grid cards ignore the stored alt.
11. No collection or home SEO fields; no SEO checks/score; no "ready for Google/Meta" panel (promised in the product
    model spec).
12. No Merchant Center / Meta catalogue feeds; no GA4/pixel/CAPI (server-side forwarding planned in the analytics spec).
13. Accessibility: no skip link (though `#main` exists), no storefront focus style; store contrast checked in vitest.
14. No e2e asserts canonical, sitemap or JSON-LD; `themes:speed` (Lighthouse) not built; no field Web Vitals (RUM).
