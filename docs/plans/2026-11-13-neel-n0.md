# Neel N0 — tokens and primitives
Status: active · Date: 2026-11-13 · Spec: `docs/specs/2026-11-13-design-language-neel.md` · Mockup: https://claude.ai/artifact/9WNgk65rAmNQagjTT2xmrx (§ Foundations, Components, More components, States) · Approved: owner, 2026-11-13 ("implement these new mockups across the system carefully")

## Goal
Every console, Frrata Admin and partner screen is drawn from Neel's tokens and primitives, so N1–N4 rebuild screens
on a finished kit. The storefront and the public website do not change (proved by the visual baseline).

## Regression net first
- `npm test`, typecheck, the full e2e suite (`npm run e2e`) before and after; `05-shop-look` pixel baseline unchanged
  (storefront untouched); `90-ux` screenshots retaken and read; `check:contrast` extended to Neel's pairs.
- The unverified PR·3 commit on this branch (option kind, chip reorder, remove confirm) runs its flows (78, 79, 65,
  05, 10) first; it ships with N0 only if green.

## Tasks
1. **Tokens, scoped to `[data-shell]`** (console, Admin, partner workspace, look editor; never the storefront or website):
   neutral steps (page white, sidebar #FBFAF9, sunk/hover #F6F5F3, soft line #EEEDEA, line #E3E1DD, button edge
   #CFCCC7, field edge #8F8A84, text #171615, text 2 #67625C); `--primary` neel 600 #3A44C2 (hover 700), ring neel 500;
   new `--bar`/`--bar-foreground` (ink, for the save bar, toasts, tooltips) so nothing dark is drawn with `--primary`;
   `--select` neel 50; `--danger-fill` #C42F2F; status tints/text/dots as drawn. Radius and shadow become variables
   (`--r-sm/md/lg/xl`, `--sh-1/2/3`) whose `:root` values equal today's (storefront unchanged) and whose shell values are
   6/8/12/16 and e1/e2/e3. `text-section` 16/24.
2. **Type:** Inter 400/500/600 in the shell; `font-display` in the shell resolves to Inter (Bricolage retires there);
   `font-bold` → `font-semibold`; page title 22/28. `<Money>`/`<Numeric>` render Inter with tabular figures; mono stays
   only on codes (SKU, AWB, GSTIN, codes, domains being copied): a sweep of the 296 `font-mono` uses, each kept or
   dropped by that rule.
3. **Primitives as drawn:** Button (primary neel; secondary white + 300 edge + e1; ghost; destructive danger-fill; link
   neel 700 underlined on hover; heights 36 / 44 on a phone; the thread removed from buttons, tabs and links), Badge
   (tint + dot + word) and a new Tag (outlined fact), ViewTabs (neel underline, count pill), DataTable (36 px sunk
   header, 48 px rows, hover and selected tints), Section (12 radius, 20 padding, 16/24 title), one field style module
   replacing the ~25 local copies, Checkbox (16 in a 24 target), Switch (off track grey 500), Segmented, Toast and
   SaveBar on `--bar`, Dialog (16 radius, e3), Menu (12 radius, e2), Badge counts.
4. **The living gallery:** `/console/fixtures/ui` shows each primitive in each state, both as drawn.
5. **Gates:** check:contrast pairs; check:hex allows the new tokens in base.css only; check:motion unchanged.
6. **Parity:** `mockup-parity-reviewer` on the gallery against § Foundations and Components; design-system-reviewer and
   impact-reviewer on the diff.
