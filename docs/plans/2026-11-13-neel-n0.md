# Neel N0 — tokens and primitives
Status: active · Date: 2026-11-13 · Spec: `docs/specs/2026-11-13-design-language-neel.md` · Mockup: `docs/mockups/2026-11-13-design-language-neel.html` (published https://claude.ai/artifact/9WNgk65rAmNQagjTT2xmrx; § Foundations, Components, More components, States, Access) · Approved: owner, 2026-11-13 ("implement these new mockups across the system carefully")

## Goal
Every console, Frrata Admin and partner screen is drawn from Neel's tokens and primitives, so N1–N4 rebuild screens
on a finished kit. The storefront and the public website do not change (proved by the visual baseline).

## Regression net first
- `npm test`, typecheck, the full e2e suite (`npm run e2e`) before and after; `05-shop-look` pixel baseline unchanged
  (storefront untouched); `90-ux` screenshots retaken and read; `check:contrast` extended to Neel's pairs.
- The unverified PR·3 commit on this branch (option kind, chip reorder, remove confirm) runs its flows (78, 79, 65,
  05, 10) first; it ships with N0 only if green.

## Order of work (architecture-reviewer and design-system-reviewer on this plan, 2026-11-13; their findings folded in)
**N0a — the base, no screen layouts change**
1. **Ink is its own token, first, with no visible change.** Add `--ink`/`--ink-foreground` (today's `--primary` values)
   and `--bar`, `--bar-foreground`, `--bar-btn`, `--bar-btn-text`, `--bar-line`, `--bar-link` at `:root`; move every use
   that means ink onto them (ink sidebar/header `app-shell.tsx`, phone nav `nav.tsx`, toast, save bar, the monogram's
   tile, the website's ink stage `brand/site.tsx`). The switch's on state stays `--primary`: the mockup draws it in the
   action colour. Baselines unchanged (the products list baseline was stale since PR·1 and is retaken first).
2. **A scope of its own: `data-neel`** on `AppShell` (console, Frrata Admin, partner workspace), their fallback `<main>`s,
   `staff-gate.tsx` and the look-editor layout. `[data-shell]` alone also covers the website and sign-in, which stay
   brand surfaces and do not change. Inside `[data-neel]`, `[data-store-theme]` (the console's shop preview, swatches)
   resets every token Neel changes to its `:root` value, so the preview matches the live store; a preview baseline
   joins `05-shop-look`.
3. **Flip the tokens under `[data-neel]` in base.css** (hex lives only there, check:hex): the list in Task 1 below plus
   `--off`, `--chart`, `--chart-now`, `--text-3`, `--link`, `--focus` (neel 500), the halo neel 100, the select pair
   neel 50/800, `--danger-fill`, `--mark-*`, the neutral tint, `--neel` kept as neel 900 for brand surfaces.
   check:contrast learns the `[data-neel]` block (light; field edge 3:1, white on neel 600, the bar link on ink).
4. **Radius and depth as variables:** `@theme` radius and shadow tokens read `--r-sm/md/lg/xl` and `--sh-1/2/3`
   (`:root` = today's values: storefront unchanged). In `[data-neel]`: 6/8/12/16 and e1/e2/e3, with 4 (checkbox, kbd)
   and 10 (toast, banner, segmented, drop zone) as `--r-xs`/`--r-mid`. Hand-written CSS reads `--r-*`, never
   `--radius-*`. `shadow-sm`=e1, `shadow-md`=e2, `shadow-lg`/`xl`=e3; the 44 existing `shadow`/`shadow-sm` uses written to
   render nothing are swept (kept only where something floats).
5. **Type:** in `[data-neel]`, `font-display` is Inter; tokens `text-title` 22/28 and `text-section` 16/24 (+ display
   30/36, label 13/18, small 12/16; phone body 15/22); weights 400/500/600 (`font-bold` → `font-semibold` in console,
   Admin, partner only — never the website). `Numeric`/`Money` become Inter tabular first (most money flips at once);
   then the 314 `font-mono` uses in 136 files are swept by the rule (mono only for SKU, AWB, GSTIN, codes, a domain
   being copied), the 7 storefront ones left alone. Kbd is 11 px Inter, radius 4.
6. **Existing primitives changed as drawn (the design-system review's list):**
   - Button: no thread (its test removed); heights 36 desktop / 44 phone; `sm` 30; secondary g300 edge + e1; ghost
     text 2; disabled 45% with the reason beside it, reachable by keyboard; busy keeps the label and adds a spinner.
   - Badge: a 22 px pill with a 6 px dot, 12/500. New `Tag`: 6 radius, a line edge, text 2.
   - ViewTabs: underline tabs with a 20 gap; count pill g100, n50/n700 when current, tabular Inter.
   - Switch: 34×20 with a 16 knob, off `--off`. Segmented control and Checkbox (16 in a 24 target) as primitives.
   - SaveBar uses Button and says "N unsaved changes" (12 radius, e3). Toast: 10 radius, e3, links in `--bar-link`.
   - Dialog: 18 padding, e3, a sheet on a phone. Menu: 12 radius, e2.
   - DataTable: header 36 sunk, 12/16 labels; rows 48; hover g25; selected n50.
   - Section: header 16/20/0, body 16/20/20, gap 16, 12 radius.
   - Fields: one style module (36/44, field edge g500, focus 2 px neel at offset 1 with the border neel; mistake =
     bad edge + 3 px halo, 13/18 error tied by aria-describedby/aria-invalid; read-only sunk) replacing ~25 local copies.
   - Focus: 2 px `--focus` at offset 2 everywhere (globals.css), fields offset 1.
   - Targets: 24 px everywhere, 44 on a phone, links and toast actions included.
   - The loading line stays rani (`nav-progress.tsx`).
7. **The gallery** (`/console/fixtures/ui`) is built alongside each step and is the parity target; axe-core runs on it.

**N0b — the primitives the console uses but Neel draws new** (each with its states, in the gallery):
KPI/stat tile, Banner (bad/warn/info/support; support and building banners fold in), Empty (first use, no match),
Locked, Skeleton (still), CopyField, Steps, SearchPicker, Select, DateField and time, unit inputs (₹ %, +91, PIN code
with city, stepper, code input), Upload (ready, over, uploading, failed), Facts, Activity feed, phone Sheet,
type-the-count confirm, long-job progress, chart tooltip and InfoTip on `--bar`.

## Tasks (as first written; superseded where the order above says more)
1. **Tokens, scoped to `[data-shell]`** (console, Admin, partner workspace, look editor; never the storefront or website):
   neutral steps (page white, sidebar #FBFAF9, sunk/hover #F6F5F3, soft line #EEEDEA, line #E3E1DD, button edge
   #CFCCC7, field edge #8F8A84, text #171615, text 2 #67625C); `--primary` neel 600 #3A44C2 (hover 700), ring neel 500;

   (`--r-sm/md/lg/xl`, `--sh-1/2/3`) whose `:root` values equal today's (storefront unchanged) and whose shell values are
   6/8/12/16 and e1/e2/e3. `text-section` 16/24.
2. **Type:** Inter 400/500/600 in the shell; `font-display` in the shell resolves to Inter (Bricolage retires there);
   `font-bold` → `font-semibold`; page title 22/28. `<Money>`/`<Numeric>` render Inter with tabular figures; mono stays
   only on codes (SKU, AWB, GSTIN, codes, domains being copied): a sweep of the 296 `font-mono` uses, each kept or
   dropped by that rule.
3. **Primitives as drawn:** Button (primary neel; secondary white + 300 edge + e1; ghost; destructive danger-fill; link

   (tint + dot + word) and a new Tag (outlined fact), ViewTabs (neel underline, count pill), DataTable (36 px sunk
   header, 48 px rows, hover and selected tints), Section (12 radius, 20 padding, 16/24 title), one field style module
   replacing the ~25 local copies, Checkbox (16 in a 24 target), Switch (off track grey 500), Segmented, Toast and
   SaveBar on `--bar`, Dialog (16 radius, e3), Menu (12 radius, e2), Badge counts.
4. **The living gallery:** `/console/fixtures/ui` shows each primitive in each state, both as drawn.
5. **Gates:** check:contrast pairs; check:hex allows the new tokens in base.css only; check:motion unchanged.
6. **Parity:** `mockup-parity-reviewer` on the gallery against § Foundations and Components; design-system-reviewer and
   impact-reviewer on the diff.
