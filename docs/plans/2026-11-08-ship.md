## Practices recorded in skills (closing each phase)
- **Architecture:** one writer of outcome dates; an unsigned webhook is a trigger read back from the provider (ADR-0006
  amendment); a connector's outbound steps are separate idempotent outbox rows keyed by our own id; amounts converted
  to paise at the connector's edge; a module's primary action through `order.primary`.
- **Testing:** a fake per provider in `e2e/fakes/`; every state the provider can send has a mapping test.
- **Design language:** rules 53–58 (landed with the approval).
