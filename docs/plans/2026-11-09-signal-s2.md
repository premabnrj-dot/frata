approved board also has the story half — a **Spotlight**, a **Story fan**, a **Statement** — a script line on the Hero,
and bigger, tighter headings. Measure: as the spec (Signal shops publishing within 7 days; add-to-bag vs same categories).

## Decisions taken from the reviews
- **S2-0, the split inverted (arch B1–B2, speed H1):** `src/app/store.css` (new) is a partial with the tokens, `@theme`,
  `@utility` and every store rule; `shop.css` = `@import "tailwindcss" source(none)` + `@source` for
  `components/storefront`, `components/modules`, `components/icons`, `app/s`, `domains/themes` + the partial; `app.css`
  = today's sheet (full auto-detection, so byte-for-byte today's) + the partial. The **root layout imports `shop.css`**;
  every non-shop entry also imports `app.css` (loaded after it, a superset, so its rules win in the right order and
  nothing can go missing): `(console)`, `(admin)`, `(lookeditor)`, `(lookpreview)`, partner, and the root-level pages
  without a group (`/`, login, start, choose, handover, partners, `not-found`, `global-error`) through their own
  `layout.tsx` (or the page for `/`). Shop pages load `shop.css` only. Console-only rules (`[data-shell]`,
  `table[data-rows]`, `[data-calc]`, dark tokens) move from the partial to `app.css`. Gates: `check-hex`,
  `check-motion`, `check-contrast` read the new files; `check-storefront-build` fails if a shop route loads `app.css`
  (a marker) or a console route misses it. The CSS budget is reset **after S2-2**, to measured + 1 kB (spec § Scalability
  updated). Verify: shop-look 0 px; console baselines added (Orders, Customize, Admin, login) before the split, then 0 px.
- **Spotlight is a layout, not a key (arch 9):** Image with text gains `layout: 'beside' | 'spotlight'` (default beside),
  offered where a theme lists it (`allowed.imageTextLayouts`, like `productLayouts`); spotlight = tile background,
  text .8fr, media 1.4fr at 16/8 (the board), phone stacked; the existing `button` is its link. Video already allowed
  there (V1). One `VIDEO_KEYS` list replaces the four hard-coded copies.
- **Lenient schemas, readiness that doesn't stop a first publish (arch 5–6):** `cards: max 7, default []`, nullable
  images everywhere (blank sections parse). Readiness: an empty section, a fan under 3 cards, a statement with no photo
  or wordmark → `add(false, '… shows nothing')` and the shop hides it; missing alt text still blocks; a linked card with
  no title and a decorative photo blocks (a nameless link). `readiness.ts` made exhaustive.
- **The type scale only where 1.2.0 sets it (arch 7):** a manifest field `scale: 'signal'` → `data-scale="signal"`;
  live Signal 1.0/1.1 shops 0 px; selector inside `:where(...)` so the merchant's text styles still win.
- **Caveat (arch 8, speed 2–3):** `next/font/local` with the committed subset + its OFL text (no Reserved Font Name to
  honour: checked before shipping), fallback the grotesk, never `cursive`; `display: swap`. Statement: the wordmark
  sits absolutely over a fixed-aspect photo (a swap moves nothing), `content-visibility: auto` with an intrinsic size.
- **Images (speed 6–7):** a section opening the page gives its photo `priority` (copy the hero's code, not image_text's);
  spotlight `sizes="(min-width: 640px) 64vw, 100vw"`; fan cards lazy, `sizes="(min-width: 640px) 22vw, 72vw"`, the
  middle card `priority` only if the fan opens the page; statement lazy, ≤ 1200 w under its scrim. `LoopPoster` gains
  a srcset.
- **Accessibility (arch 11):** the fan is a list; cards placed with `--i`/`--n` (one middle for 3–7); a focused card
  raised (`:focus-within`); titles at full contrast (only the photo fades); the phone row `tabindex=0` + label when no
  card links; fanned layout is static (no motion); reduced motion / `data-motion="none"`: side by side. Statement: no
  `aria-hidden`; scrim ≥ 60 % (4.5:1 for the 11 px eyebrow); the wordmark wraps at 360 px (≤ 2 lines, then smaller);
  statement joins the even-rhythm full-bleed exclusion.
- **Customizer JS (speed 5):** it is 205.3 kB against 190 today; the section forms load with `next/dynamic` (recorded
  before and after).
- **Smaller:** `withSampleImages` + its test cover the new photos; the sections snapshot covers the changed schemas;
  `MAX_PER_PAGE`: story_fan 2, statement 2; Signal 1.2 home baselines in `05-shop-look`; `unit-economics-reviewer` on a
  second home loop in S2-6; the muted loops' pause control (WCAG 2.2.2) recorded as existing debt.

## Design
- **Sections** (offered by Signal 1.2.0 only; older themes never render them; `made` lists them):
  - **Image with text · Spotlight** (layout above).
  - **`story_fan`** {label, heading ≤ 60, text ≤ 160, cards ≤ 7 [{image|null, title ≤ 40, link shop path|null}], scheme}.
  - **`statement`** {eyebrow ≤ 24, wordmark ≤ 32, image|null}: full-bleed photo, scrim, eyebrow in the grotesk,
    wordmark in Caveat 700 rotated −6°.
  - **Hero script line** {script ≤ 32, optional}, shown in Caveat above the heading where the theme offers it
    (`allowed.heroScript`, 1.2.0).
- **S2-4 Signal 1.2.0's home** (the board's order): hero (script line "New season", "Shop now" → /products),
  Image with text · Spotlight, bestsellers (tabs), new arrivals (rail), band, story fan, statement. Samples fill the
  photos in the preview only.
- **Customizer (owner: every option editable):** Spotlight (Image with text with Layout: Spotlight): label, heading,
  text, button, photo (upload, paste, from your products), video, side, scheme; Story fan: label, heading, text, cards
  (photo, title, optional link; add, move, remove; ≤ 7), scheme; Statement: eyebrow, wordmark, photo; Hero: the script
  line. All: add from the library ("Made for Signal"), move, hide, delete, click-to-select, Publish says what's missing.
