What to take

Skills gate

Adopt

Ekatan fails a skill without front-matter, over 500 lines, or with a changed body and the same version.

Take: all of it, extended to agents. The three long skills are held at today's length and may only shrink.

Plans gate

Adopt

Ekatan fails a plan with no **Mockup:** line or no dated **Approved:** line.

Take: both, plus a **Review:** line for each agent the plan needs. Plans from 2026-11-17 on.

Hooks and deny rules

Adopt

Rules that must never fail go in settings, not prose.

Take: deny vercel deploy and force-push to main. Run the 27 gates before every commit (6 s).

Docs that name missing files

Adopt

Ekatan fails a doc that names a file that is gone, and CLAUDE.md over 200 lines.

Take: for living docs only. Specs and plans are history and stay as written.

Doc-drift hook

Adapt

Ekatan blocks a commit that changes a file a doc covers unless the doc is in the commit or the message says why not.

Take: on files a doc names exactly. Tried on the last 300 commits, it would stop 39%. Frrata's broad doc patterns would make it 57%, so we narrow them.

Evals

Adapt

Ekatan runs each skill's scenarios in a headless session and has a second session grade them.

Take: agents first. Test plans with a known mistake for the 4 reviewers of data isolation, security, money and architecture. Run before a big version change, not on every commit.

Generated reference pages

Adapt

Ekatan regenerates six pages (gates, schema, routes …) from the code on every commit.

Take: the gates page only. It is the one Frrata copies by hand today.

Migrations and JS budget

Adapt

Ekatan has a journal gate and a first-load JS budget per shopper page.

Take: Frrata has both halves already. The journal check moves into npm test; Console and Admin join the store's budget check.

Planning headings

Adopt

The proposal opens with In short, Audit, What we took, Your calls. A spec has a Stress test and an After deploy check. A number on a mockup comes from the engine.

Take: into frata-planning. This page uses the opening.
