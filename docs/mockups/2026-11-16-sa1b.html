Bag link

Send the shopper's bag to the store's checkout with one link.

GEThttps://checkout.kesarstudio.in/cart?l=<size id>:<qty>,…
PartRule
lUp to 20 lines. A size's id from products/{handle}, then 1–10.
codeAn offer code. Optional.
utm_*Pass the shopper's own tags on. Optional.
 
https://checkout.kesarstudio.in/cart?l=8f2c…e1:1,41ab…09:2&utm_source=instagram

The store's checkout prices the bag again. A size that sold out drops out there.

The store's address is checkout in the shop answer.
