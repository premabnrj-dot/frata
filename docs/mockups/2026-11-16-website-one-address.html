In short

  • What to take. Settings › Website for a code site on Frrata’s account. One address, the store’s own domain or house-of-ayuda.frrata.shop. Two records shown with their state. The live version and the latest preview. Build keys listed beside the live and test keys, each deletable by the owner.
  • For the partner. New website on the client’s page makes the code, the preview and the address. Publish sets the version the store opens with. Hand over stays where it is.
  • For the brand. The accept page names the version being accepted. Shoppers meet a “We’ll be back soon” page if the website stops answering, while checkout and orders keep working.
  • Why now. V2a and P5 are approved (owner, 16 Nov: “approve all”). Nothing in either is built before this mockup is approved.
  • What it costs. No new price on any screen. Hosting stays unpriced until the pilot’s 30 days are measured (decisions S18, O16).
  • What is needed from you. A yes on the screens, and the calls below.
