Sizes and colours, edge cases

RENAME AND REORDER

Click a chip to rename it; its cells, photos and SKUs move with it. Drag the handle (or Alt+arrow keys) to reorder; the shop's size buttons follow. "xl" when "XL" exists is refused as you type.

ONE SIZE

A saree, dupatta, jewellery or a bag has no Size and no size chart or model sections; colours are optional. Changing kind later asks first: "Remove Size and its 18 rows?"

COLOUR, WHATEVER IT'S CALLED

Colour, Shade, Print or रंग: any option the brand marks as colour gets swatches (a colour, or cut from a photo) and photos per colour.

SIZE CHART FITS THE SIZES

Publish checks the chart's rows match the product's sizes. Columns can be removed; cells take decimals (23.5 cm).

Your calls

  1. Start from the kind (Clothing with sizes, Footwear, Kids, One size), which sets sizes, chart, HSN and sections. Recommended.
  2. One Save for the whole page, explicit, sticky, ⌘/Ctrl+S, Back protected; no autosave (as Shopify keeps for products). Recommended.
  3. Add an Unlisted status: reachable by its link, out of search, collections and the sitemap (for Instagram DM drops). Recommended.
  4. Delete only what was never live and never ordered; everything else archives, with Undo either way. Recommended.
  5. The address follows the name until first live, then stays; changing it later redirects automatically. Recommended.
  6. The share card becomes a full-website card (photo, logo, name, price, address) and the editor previews it from the draft. Recommended.
  7. Phases: PR·0 fixes what's broken first (the 50-product list, saving drafts without prices, renames wiping prices, size order, the wrong size chart, decimals, Sold out on made-to-order), then the list, the editor, variants, links. Recommended.
