Frrata Studio: an agent that builds a shop's website, the way Claude Code works in the cloud

Partners first. Every website is a repository; every piece of work is a session the agent runs in its own sandbox, on its own draft, with a live preview beside it. A partner can watch it, steer it, run three ideas at once, schedule it, take the code to their own laptop, and publish when the checks and the client say yes.

How we charge

Frrata already earns on every delivered order (2% Launch, 1% Growth, 0.5% Scale) plus the plan fee. A website built on the API sends its orders through Frrata's checkout, so more API traffic is more orders. The principle: never charge for the traffic that brings orders; charge for what costs Frrata money to run on someone's behalf: agent work, builds and heavy hosting.

What a credit is

One credit is one ordinary turn of the agent (a request and the work it does) and sells at ₹19: three times what it costs Frrata (owner, 2026-11-11: resold API costs sell at 3×). A turn that builds and runs the checks counts a little more; a turn on the larger model counts double. Every session shows its estimate before it starts and stops at its cap, never half-way through a page. A small change takes 1–2 credits (₹19–38), a new page 10–30 (₹190–570), three variants about 20 (₹380). Credits on a seat reset monthly; packs last 12 months (the market's norm).

Against the market

No commerce platform charges per Storefront API call for shopper traffic: Shopify's is free with no fixed limit for buyers and throttles only bots; BigCommerce limits by plan; Swell meters at $5 per 100,000 calls on its own plans. Builders sell credits: Lovable at $0.25–0.50 a credit (a landing page ≈ 1.7 credits), Framer 3,000 credits in $30, Bolt and v0 by tokens. Shopify bundles Hydrogen hosting into every paid plan. Frrata's line: the API and hosting come with the plan (orders pay), the agent's work is credits at three times its cost, a stated rupee price, with an estimate before every run.

Questions for you

1. Seat prices. At 3×: Studio ₹2,999 with 150 credits, Studio Plus ₹9,999 with 500. Lovable sells at ₹22–44 a credit, so ₹19 is still below it. Right shape for Indian agencies?
2. Who carries a client's credits. Partner by default with an opt-in to the client's invoice (proposed), or always the client?
3. Routines that publish. Allowed per routine when checks pass (proposed), or always a person?
4. Client approval. Required before every publish (proposed), or the partner's choice per client?
5. Brands' own developers. Free git and API access on every plan (proposed), with Studio seats for partners only until V3b?
6. Model. Run the agent on Anthropic's API through Frrata's account (proposed; the Agent SDK can't offer Claude sign-in or use Claude Code's name), or on Anthropic's managed agents?
