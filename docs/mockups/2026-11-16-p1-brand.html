In short

  • What: one page, Console › Brand, where a code-site store keeps its logo files, colours, fonts, corners and spacing. Checkout, emails, invoices, share images, the API and the website read it.
  • Why now: House of Ayuda's logo lives in its website's code and nowhere in Frrata (shop.logo is null). P2 draws checkout from this record.
  • Cost: two tables, one save, one page (plan P1·1–P1·9). Nothing changes for theme shops (O19).
  • Needed from you: approve this page, and the six calls below.

What to take

Shopify checkout branding API

shopify.dev “Styling”, read 16 Nov 2026 (spec § Research). Colours, typography, corner radius and header alignment from a closed set, one style for every checkout page. SVG not supported; Plus only.

Take: design as data from closed sets. Skip: the Plus gate; SVG is taken, cleaned.

House of Ayuda’s design system

mokobara/docs/design/house-of-ayuda-design-system.md v1, 16 Nov 2026. Colour by role, each pair’s contrast computed, one failing pair named (stone on sand, 2.77:1).

Take: roles, not swatches; every pair checked and shown. The record holds its eleven colours.

Frrata’s own Look

src/domains/themes/types.ts and contrast.ts, read 16 Nov 2026. Six fonts, six accents, the WCAG check.

Take: the font list and the contrast rule, unchanged. Skip: the accent enum for code sites.
